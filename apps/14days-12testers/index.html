14Days-12Tester Pro

Servicio Android para coordinar pruebas cerradas y feedback operativo sobre una app del cliente.

com.dharmaapps.fourteendays12testerproCandidato 0.1.0 (1)Auditoría: 17/08/2026
AndroidCuentasGoogle Play BillingSin anunciosSin analítica integradaAdultos

Declaración auditada

14Days-12Tester Pro permite crear una cuenta, enviar los datos de una app Android y adquirir un servicio único por app para coordinar participantes de prueba y feedback operativo. Google Play conserva sus propias decisiones sobre pruebas, revisión y publicación.

ResponsableDharma-Labs · Uruguay · contacto@dharma-uy.com
Versión auditada0.1.0, versionCode 1. La AAB de release firmada y la ficha final de Play todavía requieren la clave de firma y credenciales de publicación.
SDK y plataformaAndroid nativo; min SDK 26, compile SDK 36 y target SDK 36. AndroidX, Jetpack Compose y Google Play Billing Library 9.1.0.
PermisosÚnicamente INTERNET. No se declararon cámara, micrófono, ubicación, contactos, teléfono, fotos, Advertising ID ni inventario de apps. Android Backup está desactivado para la app.
CuentasRegistro y acceso por email, contraseña y nombre visible. La contraseña se almacena como hash en el servidor; la sesión usa un token temporal. La app Android mantiene el token en memoria y el portal web lo guarda en localStorage del navegador.
BackendAPI Fastify con PostgreSQL. Registra solicitudes, estados operativos, asignaciones, eventos y auditoría de servicio. El proveedor de hosting, región, backups y monitorización de producción aún no están verificados.
Datos tratadosEmail, nombre visible, hash de contraseña, datos de la app (nombre, package ID, enlace de prueba cerrada y notas), estado del servicio, asignaciones de testers y metadatos de compra/operación.
ComprasProducto único de Google Play testing_service_14days_12tester, precio de referencia USD 14,99 antes de la localización de Play. El servidor verifica el token con Google Play Developer API en producción y lo guarda sólo como hash; conserva metadatos mínimos de verificación y transacción.
Publicidad y analíticaNo se encontró integración de anuncios, AdMob, Firebase Analytics, Crashlytics, Sentry, PostHog, Mixpanel ni otro SDK de analítica en el código auditado. Esto no equivale a afirmar que proveedores futuros no puedan cambiar esa situación.
Datos compartidosEl token de compra se envía desde la app a la API y la API lo consulta a Google Play Developer API para verificar la compra. No se envían datos del cliente a redes publicitarias. El proveedor de infraestructura de producción queda pendiente de confirmar.
RetenciónNo existe todavía un job automático de expiración ni una política técnica de backups de producción verificada. Al eliminar la cuenta se eliminan sesiones, se anonimizan credenciales y se eliminan notas; pueden conservarse registros mínimos de transacciones, seguridad y auditoría cuando exista una obligación legítima.
EliminaciónEl portal incluye la acción “Eliminar cuenta” y existe un canal web específico. También puede solicitarse por email sin enviar la contraseña.
Público objetivoDesarrolladores y equipos adultos; no está dirigido a niños. La clasificación y declaración de público de Play Console siguen pendientes.
Contenido de usuarioEl cliente envía datos de su app y notas privadas para la coordinación. No hay feed público, chat entre usuarios ni reseñas incentivadas dentro de la app.
Límites verificables: esta ficha se basa en el código fuente, el manifest, el lockfile y el APK debug auditado. No confirma aún la AAB final firmada, una compra real de Play, el proveedor de producción, las copias de seguridad, la configuración de Play Console, la DNS del dominio personalizado ni la revisión de Google.

Product legal entry · Uruguay

14Days-12Tester Pro

An Android service for coordinating closed testing and operational feedback for a customer's app.

com.dharmaapps.fourteendays12testerproCandidate 0.1.0 (1)Audit: August 17, 2026
AndroidAccountsGoogle Play BillingNo adsNo integrated analyticsAdults

Audited statement

14Days-12Tester Pro lets a customer create an account, submit Android app details, and purchase one service per app to coordinate test participants and operational feedback. Google Play retains its own decisions about testing, review, and publication.

ControllerDharma-Labs · Uruguay · contacto@dharma-uy.com
Audited version0.1.0, versionCode 1. The signed release AAB and final Play listing still require the signing key and publishing credentials.
SDK and platformNative Android; min SDK 26, compile SDK 36, and target SDK 36. AndroidX, Jetpack Compose, and Google Play Billing Library 9.1.0.
PermissionsOnly INTERNET. No camera, microphone, location, contacts, phone, photos, Advertising ID, or installed-app inventory permissions were declared. Android Backup is disabled for the app.
AccountsEmail, password, and display-name registration and sign-in. Passwords are stored as server-side hashes; sessions use a temporary token. Android keeps the token in memory and the web portal stores it in browser localStorage.
BackendFastify API with PostgreSQL. It records requests, operational states, assignments, events, and service audit data. The production hosting provider, region, backups, and monitoring are not yet verified.
Data processedEmail, display name, password hash, app details (name, package ID, closed-testing link and notes), service state, tester assignments, and purchase/operational metadata.
PurchasesGoogle Play one-time product testing_service_14days_12tester, reference price USD 14.99 before Play localization. In production, the server verifies the token with the Google Play Developer API and stores only a hash of the token plus limited transaction metadata.
Advertising and analyticsNo ads, AdMob, Firebase Analytics, Crashlytics, Sentry, PostHog, Mixpanel, or other analytics SDK integration was found in the audited code. This does not prevent a future provider change.
Data sharingThe purchase token is sent from the app to the API, and the API queries Google Play Developer API to verify it. Customer data is not sent to advertising networks. The production infrastructure provider remains to be confirmed.
RetentionNo automatic expiry job or verified production-backup policy exists yet. Account deletion removes sessions, anonymizes credentials, and clears notes; limited transaction, security, and audit records may remain where there is a legitimate legal or operational reason.
DeletionThe portal includes a “Delete account” action and a dedicated web channel. Requests may also be sent by email without sharing a password.
Target audienceAdult developers and teams; not directed to children. Play Console audience and content declarations remain pending.
User contentCustomers submit app details and private notes for coordination. There is no public feed, user-to-user chat, or incentivized review flow.
Verifiable limits: this entry is based on source code, the manifest, the lockfile, and the audited debug APK. It does not yet confirm the final signed AAB, a real Play purchase, the production provider, production backups, Play Console configuration, custom-domain DNS, or Google's review.
