Términos de Block Tower 2000

Este anexo complementa los términos generales de Dharma Labs.

com.dharmaapps.blocktower2000Vigencia: 14/08/2026

Al instalar o jugar Block Tower 2000 aceptas los términos generales y este anexo.

1. Producto

Es un juego casual de apilado para Android, diseñado para funcionar offline y con control táctil. No requiere cuenta, anuncios, compras ni suscripción.

2. Edad y supervisión

El juego está dirigido principalmente a una audiencia familiar de aproximadamente 7 a 12 años. Si el jugador es menor, su madre, padre o tutor debe supervisar la descarga y cualquier contacto con soporte. El juego no solicita datos personales para jugar.

3. Progreso y elementos virtuales

Récord, monedas y aspectos se obtienen jugando y se guardan localmente. No tienen valor monetario, no pueden venderse ni transferirse y pueden perderse si borras datos o desinstalas sin una copia compatible.

4. Copia de seguridad

Android puede restaurar datos mediante Auto Backup bajo la cuenta Google del usuario. La disponibilidad y resultado de esa restauración dependen de Android y del dispositivo, por lo que no se garantiza una recuperación en todos los casos.

5. Juego limpio

No está permitido modificar o automatizar el juego para distribuir versiones engañosas, extraer activos para reventa, eludir controles o afectar la seguridad. Jugar offline para uso personal está permitido.

6. Actualizaciones

Podemos ajustar balance, dificultad, presentación y compatibilidad. Procuraremos preservar guardados compatibles, pero cambios técnicos importantes pueden requerir migraciones.
