# Legales Dharma Labs

Portal legal público y bilingüe para las aplicaciones, juegos y servicios digitales publicados por Dharma Labs.

Sitio: `https://dharma-apps.github.io/Legales-Dharma-Labs/`

## Modelo documental

- `/privacy/`: marco general de privacidad.
- `/terms/`: términos generales de uso.
- `/account-deletion/`: proceso general para cuentas remotas y datos locales.
- `/apps/`: registro de productos auditados.
- `/apps/<slug>/`: anexo específico de cada producto.

La política general no debe enlazarse sola en una tienda si existe un anexo específico. Cada producto futuro requiere auditar su build, permisos, SDK, backend, cuentas, publicidad, compras, analítica, retención y público antes de incorporarlo.

Para incorporar otro producto con Codex, usar [`PROMPT-PARA-CODEX.md`](PROMPT-PARA-CODEX.md) y completar [`templates/APP-LEGAL-AUDIT.md`](templates/APP-LEGAL-AUDIT.md). Todos los productos comparten este único sitio de GitHub Pages; no se crea un sitio separado por aplicación.

## Publicación

Sitio HTML/CSS/JS estático, sin cookies, formularios, analítica, dependencias ni secretos. GitHub Pages publica desde la raíz de `main`.

## Aviso

Estos documentos constituyen una base operativa de transparencia y cumplimiento; no sustituyen asesoramiento jurídico profesional para productos regulados, cuentas infantiles, pagos, salud, finanzas o tratamientos de alto riesgo.
